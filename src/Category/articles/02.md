# 二、范畴

1\. 一个范畴 $\mathcal{C}$ 由对象（Object）和态射（Morphism）组成，并且满足复合律（Composition），恒等律（Identity）和结合律（Associativity）。

1.1.0. 态射（Morphism）通常可以理解为一个箭头，从起点指向终点，态射的起点和终点都是对象（Object）。

1.1.1. 在本系列文章中，用 $f$、$g$、$h$ 之类的小写字母表示态射。

1.1.2. 一个范畴 $\mathcal{C}$ 中的所有态射记为 $\text{mor}\,\mathcal{C}$，对一个 $f \in \text{mor}\,\mathcal{C}$，它的起点和终点也一定属于 $\mathcal{C}$。

1.1.3. 态射的起点和终点可以是同一个对象。

1.2.0. 对象（Object）通常可以理解为一个点，它没有自身的属性，仅仅用于作为态射的起点和终点的标识。

1.2.1. 在本系列文章中，对象用 $A$、$B$、$C$ 之类的大写字母表示，值得注意的是在原版教程中，Bartosz Milewski 常用小写的 $a$、$b$、$c$ 表示对象，但本文中 $a$、$b$、$c$ 将尽量不做用途。

1.2.2. 一个范畴 $\mathcal{C}$ 中的所有对象记为 $\text{ob}\,\mathcal{C}$，对于一个 $f: A \to B$，$f$ 的起点记为 $\mathrm{dom}(f) = A$，$f$ 的终点记为 $\mathrm{cod}(f) = B$，它们沿用了定义域和值域的概念，但我们通常理解它们是箭头的起点和终点就行。

1.2.3. 一个范畴 $\mathcal{C}$ 中，以 $A$ 为起点，以 $B$ 为终点的态射可以记为 $\mathcal{C}(A, B)$，以 $A$ 为起点，任意终点的态射可以记为 $\mathcal{C}(A, -)$，同样任意起点，以 $B$ 为终点可以记为 $\mathcal{C}(-, B)$。

1.2.4. 如下图所示，范畴 $\mathcal{C}$ 中 $\text{ob}\,\mathcal{C} = \{A, B\}$，$\mathcal{C}(A, B) = \{f, g\}$，即 $f$ 和 $g$ 都是从 $A$ 到 $B$ 的态射，$\mathrm{dom}(f) = \mathrm{dom}(g) = A$，$\mathrm{cod}(f) = \mathrm{cod}(g) = B$。注意 $\text{mor}\,\mathcal{C}$，$\text{ob}\,\mathcal{C}$，$\mathcal{C}(A, B)$ 都构成集合，所以这里就自然的使用了集合运算的符号。

![图 3　范畴 C](../assets/category-example.svg)

1.3. 在继续说明之前，先用类型范畴进行对照，在类型范畴 $\mathcal{T}$ 中，态射就是一个函数，而对象则是类型。如果仅放在 TypeScript 中，态射就是一个指定了起点和终点类型的纯函数。

1.3.1. 比如 `f = x => x + 1`，作为一个函数，它的起点是 $\mathrm{Int}$ 终点也是 $\mathrm{Int}$，那么我们可以记作 $f: \mathrm{Int} \to \mathrm{Int}$ 是一个态射，用上述的范畴论的概念来表示，$f \in \text{mor}\,\mathcal{T}$，$\mathrm{Int} \in \text{ob}\,\mathcal{T}$，$f \in \mathcal{T}(\mathrm{Int}, \mathrm{Int})$，$\mathrm{dom}(f) = \mathrm{cod}(f) = \mathrm{Int}$。（注：为了和范畴论统一，类型统一为大写写法。）

1.3.2. 比如 `g = x => String(x)`，作为一个函数，它的起点是 $\mathrm{Int}$ 终点是 $\mathrm{String}$，则可以记作 $g: \mathrm{Int} \to \mathrm{String}$，$g \in \mathcal{T}(\mathrm{Int}, \mathrm{String})$，相同的函数实现也可以是 $g: \mathrm{String} \to \mathrm{String}$，$g \in \mathcal{T}(\mathrm{String}, \mathrm{String})$。这个例子说明态射必须指定起点和终点的对象。所以严格来说在给出态射的实现的时候，还需要给出类型。但要是总是这样写就太繁琐了，所以通常在没有歧义的时候省略起点和终点的类型自行推断。

1.3.3. 考虑 `f = x => x + 1`，`g = x => x + 2`，`h = x => x + 3`，$f, g, h \in \mathcal{T}(\mathrm{Int}, \mathrm{Int})$，也就是说固定一组起点和终点，可能会有无数个态射。

1.3.4. 但再考虑 `f = (x: Null) => Null`，$f \in \mathcal{T}(\mathrm{Null}, \mathrm{Null})$，由于 Null 只存在一个，$\mathcal{T}(\mathrm{Null}, \mathrm{Null})$ 的数量只可能为 $1$，我们找不到任何一个其他的函数。同样的 $\mathcal{T}(\mathrm{Boolean}, \mathrm{Boolean})$ 的数量是 $4$ 个，分别是 `x => x`，`x => !x`，`x => true`，`x => false`。

![图 4　Type 中 Boolean -> Boolean 的四个态射](../assets/boolean-endomorphisms.svg)

1.3.5. 类型范畴 $\mathcal{T}$ 是所有的纯函数和所有的类型的总和，只要是能够定义的纯函数和类型就均存在于 $\mathcal{T}$ 中。过去现在和未来的所有函数式代码都可以在类型范畴中研究，类型范畴中的所有结论也对过去现在和未来的所有函数式代码生效。一证永证。

2\. 仅仅是态射和对象不能构成范畴，还需要满足三个条件。

2.1. 复合律：如果 $f \in \mathcal{C}(A, B)$，$g \in \mathcal{C}(B, C)$，很自然的，我们相当我们可以从 $A$ 沿箭头 $f$ 前往 $B$ 然后再沿箭头 $g$ 前往 $C$，这个动作成为复合，复合律强制这条新的路径 $g \circ f$ 必须要属于 $\text{mor}\,\mathcal{C}$。$\circ$ 即复合运算符，表示先应用 $f$ 再应用 $g$，不妨将结果命名为 $h$，$h = g \circ f$，$h \in \text{mor}\,\mathcal{C}$，$h \in \mathcal{C}(A, C)$。

![图 5　范畴 C 中 f、g 复合得到 h](../assets/composition.svg)

2.1.1. 对于范畴内的所有态射，复合律必须成立，否则就不构成范畴。

2.1.2. 考虑类型范畴 $\mathcal{T}$ 上的 `f = x => x + 1`，`g = x => x + 2`，`h = x => x + 3`，$h = g \circ f$，同样的 $h = f \circ g$，但这是巧合。

2.1.3. 考虑类型范畴 $\mathcal{T}$ 上的 `f = x => x + 1`，`g = x => x ** 2`，$g \circ f$ 和 $f \circ g$ 就是不一样的，前者表示先 +1 再平方，后者表示先平方再 +1。

2.1.3.1. 再特殊说明一下，`h = x => (x + 1) ** 2` 和 `h = x => x ** 2 + 2 * x + 1` 并不说明这是两个态射，因为这只是写法不一样，但对于任何的输入，这两个函数的输出都完全一样，所以这是两个完全一致的函数，在类型范畴中也就是同一个态射。

2.1.4. 考虑复合律不成立的情况：剪刀石头布的游戏可以定义一种箭头表示获胜，那么我们尝试认为 $\text{ob}\,\mathcal{C} = \{\text{Rock}, \text{Scissor}, \text{Paper}\}$，$\text{mor}\,\mathcal{C} = \{f: \text{Rock} \to \text{Scissor}, g: \text{Scissor} \to \text{Paper}, h: \text{Paper} \to \text{Rock}\}$，然而非常可惜，因为 $g \circ f$ 并不存在于 $\text{mor}\,\mathcal{C}$ 中，石头剪刀布游戏也就不构成一个范畴。

2.1.5. 然而并不是说我们不能在范畴论中定义出石头剪刀布游戏，最简单的，我们当然可以在类型范畴 $\mathcal{T}$ 中定义出这个游戏，但此时的箭头 $\to$ 是纯函数的含义，而不是上面的获胜的含义。

2.1.6. 另外一提，态射可以不是那么稠密的，对象和对象之间没有任何态射的情况也可以存在，也就是可以存在 $|\mathcal{C}(A, B)| = 0$ 的情况，后续文章中我再举一些例子。

2.2. 对范畴中的所有对象都必须有 Identity，使得对任意的 $f \in \mathcal{C}(A, B)$ 以及 $g \in \mathcal{C}(C, A)$ 有 $f \circ \mathrm{id}_A = f$，$\mathrm{id}_A \circ g = g$，有时候我们也会记为 $\mathrm{id}$、$\mathrm{id}_A$、$1$ 或者 $1_A$，考虑到 $\mathrm{id}$ 的起点或终点可以从和它复合的态射中推断，所以有时不写。

2.2.1. 考虑 $f \circ \mathrm{id}_A = f$，意味着 $\mathrm{id}_A$ 并没有改变 $f$ 的行为。在类型范畴中 `id = x => x`，并且对任意的类型都对应一个具体态射，比如 $\mathrm{id}_{\mathrm{Int}}: \mathrm{Int} \to \mathrm{Int}$ 实现为 `idInt = x => x`。

2.2.2. $\mathrm{id}_A \circ \mathrm{id}_A = \mathrm{id}_A$。

2.2.3. 1.3.4 中的 `x => x` 就是 $\mathrm{id}_{\mathrm{Boolean}}$。

2.2.4. 举例 $\mathrm{Int}$ 上，数字作为对象，分别取 $>$ 和 $\geq$ 作为态射（当有 $>$ 关系时有箭头，没有 $>$ 关系时没有箭头，也就是 $|\mathcal{C}(3, 2)| = 1$，$|\mathcal{C}(2, 3)| = 0$ ），它们都是满足复合律的。比如 $3 > 2$，$2 > 1$，所以 $3 > 1$，因为 $>$ 可以传递（$\geq$ 也是）。然而我们考虑 Identity 这个条件，$>$ 并没有 Identity 而 $\geq$ 有 Identity，所以只有 $\geq$ 才能构成范畴，$>$ 不能构成范畴。因为诸如 $1 > 1$ 是不成立的。

![图 6　整数上以 ≥ 为态射构成的范畴，其中 3≥1 是 3≥2 和 2≥1 的复合](../assets/integer-geq.svg)

2.3. 结合律: 若 $A, B, C, D \in \text{ob}\,\mathcal{C}$，$f \in \mathcal{C}(A, B)$，$g \in \mathcal{C}(B, C)$，$h \in \mathcal{C}(C, D)$，则有 $h \circ (g \circ f) = (h \circ g) \circ f$。

2.3.1. 在类型范畴中是满足的，有三个运算依次进行，先合并前两个运算，还是先合并后两个运算，结果是不会变的。

2.3.2. 结合律后续遇到的比较少，这里就不举反例了。
